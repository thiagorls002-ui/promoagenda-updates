# Atualizações do PromoAgenda

Distribuição dos dois painéis PromoAgenda para Windows 11.

- Nunca publicar senhas, arquivos `.env`, sessões WhatsApp, QR Codes ou dados de clientes.
- Verificar autenticidade e integridade de cada atualização.
- Exigir confirmação e backup antes de atualizar.
- Manter independentes as instâncias das portas 3000 e 3001.
- Não expor acesso ao Docker pelo painel web.

A publicação e o atualizador automático ainda estão em configuração.
